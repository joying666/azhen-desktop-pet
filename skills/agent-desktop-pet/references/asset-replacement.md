# 素材替换指南

## 目标

大多数用户只需要替换媒体文件，不应该被要求修改 App 代码。

## 文件夹

在桌宠项目里使用这个文件夹：

```text
08_可替换素材/
```

## 必需槽位

| 槽位 | 文件名 | 推荐行为 |
|---|---|---|
| working | `任务进行中_无缝循环` | 透明背景无缝循环 |
| done | `任务完成` | 一次性动作，播放后回到暂停/休息 |
| failed | `任务失败` | 一次性动作，播放后回到暂停/休息 |
| paused | `任务暂停_休息_无缝循环` | 透明背景无缝循环 |
| water | `喝水提醒` | 一次性动作或短循环，按设置停留后回到进行中 |

通常按下面的扩展名优先级读取：

```text
.gif -> .webp -> .webm -> .apng -> .png -> .mp4
```

如果同一个槽位同时存在多个扩展名，建议移走低优先级文件，避免用户混淆。

## 人工检查清单

- 角色全身完整可见。
- 透明背景在棋盘格或桌面上显示正常。
- 长时间状态循环顺滑。
- 完成/失败的符号在小尺寸下仍然可读。
- 5 个文件名清晰易懂，并且匹配标准文件名。
- 替换文件后，重启或重新加载桌宠。

## 不要提交到公开仓库

除非用户明确希望公开自己的角色素材，否则不要把用户私有 IP 素材提交到公开仓库。
