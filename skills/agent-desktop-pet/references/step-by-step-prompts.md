# 不会使用 Skill 时的分步提示词

这份文档给不会安装或调用 Skill 的用户使用。用户只需要把每一步提示词复制到自己常用的 AI 工具里，按顺序完成桌宠素材制作。

推荐顺序：

```text
1. 多状态静态图元提示词 -> 2. 静态图质检 -> 3. 图生视频提示词 -> 4. MOV 命名与交付 -> 5. MOV 转 WebM
```

## 使用前准备

用户至少需要准备：

```text
1. 一张卡通 IP 角色参考图。
2. 想让桌宠呈现的状态或动作。
3. 想使用的生成工具，例如即梦、可灵、Runway、Pika、Lovart、Nano Banana Pro 等。
```

如果用户不知道需要哪些状态，默认使用 5 个标准状态：

```text
任务进行中、任务完成、任务失败、任务暂停/休息、喝水提醒
```

## 第一步：多个不同状态的静态图元提示词

把下面这段复制给 AI，并附上角色参考图。

```text
你是一个 Agent 桌宠静态素材提示词设计师。我要用一张卡通 IP 参考图制作桌宠素材。请你只生成“多个不同状态的静态生图提示词”，不要输出其它阶段内容。

我的目标：
把同一个卡通 IP 角色做成桌宠静态素材，在不同 Agent 状态下显示不同动作。所有图片必须是“纯绿幕背景上的单个桌宠角色素材”，不是场景插画、不是办公照片、不是电影截图、不是房间画面。

合格参考样式：
画面应接近“纯绿幕前的 Q 版角色 + 简化道具组合立绘”。例如任务进行中可以是角色坐在小椅子上，面前有简化小桌和笔记本电脑，角色、桌子、椅子、电脑全部完整入画；背景仍然只有纯绿色，不出现房间、墙面、地板、真实办公桌、环境光或室内透视。道具是桌宠动作的一部分，不是一个完整办公场景。

默认状态：
1. 任务进行中：角色原地认真打字、思考或工作。可以出现简化小桌、小椅子、笔记本电脑或小键盘；这些道具必须像桌宠小道具一样完整入画，不能变成真实办公室、大桌子、大显示器、深色办公场景或屏幕光氛围图。
2. 任务完成：角色用手举起一个白色圆形手持牌。牌子必须由白色圆形牌面和白色圆柱手柄组成，角色的手必须握住手柄，牌面上有一个清晰的绿色正确勾号。绿色勾号必须和绿幕背景明显区分，不能被当成背景。
3. 任务失败：角色用手举起一个白色圆形手持牌。牌子必须由白色圆形牌面和白色圆柱手柄组成，角色的手必须握住手柄，牌面上有一个清晰的红色叉号。不要把红叉画成头顶悬浮符号。
4. 任务暂停/休息：角色闭眼休息、躺平或安静待命。
5. 喝水提醒：角色正在喝水或举起水杯提醒喝水，手里不要拿带文字的卡片。

如果我提供了其它状态，请用我的状态替换默认状态。

对/错手持举牌硬性规则：
只要状态含义是“完成、正确、通过、成功、done、correct、approved”，就必须画成角色手持白色圆形牌，白色圆柱手柄，牌面上是绿色正确勾号。
只要状态含义是“失败、错误、不通过、驳回、failed、wrong、rejected”，就必须画成角色手持白色圆形牌，白色圆柱手柄，牌面上是红色叉号。
这两个状态都必须让角色的手明确握住牌柄，牌子与手有接触，手柄可见。禁止把勾号或叉号画成头顶漂浮 icon、悬空符号、背景符号、额头符号、角落贴纸或单独的大叉/大勾。禁止只画双手抱歉手势却没有手持牌。

静态图片文件名硬性规则：
生图阶段的图片文件名必须使用当前桌宠工程的静态图命名格式，不要使用 WebM 的无缝循环后缀。5 个标准状态对应：
1. 任务进行中 -> 任务进行中.png
2. 任务完成 -> 任务完成.png
3. 任务失败 -> 任务失败.png
4. 任务暂停/休息 -> 任务暂停.png
5. 喝水提醒 -> 喝水提醒.png

注意：`任务进行中_无缝循环.webm` 和 `任务暂停_休息_无缝循环.webm` 是后续视频/WebM 文件名，不是静态图片文件名。静态图片不要写成 `任务进行中_无缝循环.png` 或 `任务暂停_休息_无缝循环.png`。

请你先从参考图中提炼“角色身份锁定块”，包括角色的头身比、脸型、发型、服装、主要配色、画风、五官比例和整体气质。不要编造参考图中不存在的细节。

然后为每个状态输出一条静态生图提示词。每条提示词必须把下面这些硬性约束写进去，不能省略：

【画面类型硬性约束】
这是一张桌宠角色素材图，不是完整场景图。画面里只能有角色和完成动作所必需的简化道具组合。允许小桌、小椅子、笔记本电脑、杯子、牌子、键盘等桌宠道具，但它们必须像绿幕前的独立道具立绘一样存在。禁止生成房间、办公室、墙面、地板、灯光环境、真实摄影感背景、暗色背景、渐变背景。

【绿幕背景硬性约束】
背景必须是纯色 chroma key green 绿幕，建议颜色 #00FF00 或接近纯绿。背景必须平整、均匀、无纹理、无阴影、无渐变、无光斑、无景深、无地面线、无房间透视。角色和道具边缘要干净，不能出现绿色反光、绿色污染或半透明绿边。

【不出框硬性约束】
角色、头发、手、脚、裙摆、鞋子、耳环、牌子、杯子、电脑、键盘、桌子、椅子等全部元素必须完整在画面内部。任何元素都不能碰到画面边缘，不能被裁切，不能出画。整体组合可以像参考图一样占画面主体，但必须保留清楚的纯绿安全边距：顶部和底部至少 6%-10%，左右至少 10%-16%。角色加道具的整体高度建议占画布高度 78%-88%，不能超过 90%；整体宽度建议占画布宽度 60%-78%，不能超过 82%。

【角色比例硬性约束】
保持参考图的同一个角色，头身比、脸型、五官、发型、服装、配色和画风不变。禁止把角色画高、画瘦、拉长腿、缩小头、改变年龄、改变体型、改变服装主色。动作需要更多空间时，只允许整体等比缩小，不能改变身体比例。

【构图硬性约束】
1:1 正方形，单个角色居中，正面或轻微正面视角，平视镜头，近似正交视角。禁止俯视、仰视、斜向透视、广角透视、电影镜头、近景特写、半身图、只画头肩、侧脸大角度。

【道具硬性约束】
道具必须简化、可爱、完整入画，并围绕角色布置。任务进行中可以有简化小桌、小椅子、笔记本电脑或小键盘，效果应像参考图：角色坐在绿幕前的小桌旁，笔记本放在桌上，桌腿和椅子完整可见。不能出现大型办公桌、台式大显示器、真实电脑桌、房间环境，也不能让电脑遮住角色脸部、头发或主体轮廓。完成、失败、喝水等状态不要用写着文字的卡片表达动作。

【完成/失败手持牌硬性约束】
任务完成和任务失败不能只用表情、手势或悬空图标表达。任务完成必须是角色手持白色圆形牌，白色圆柱手柄，牌面绿色勾号；任务失败必须是角色手持白色圆形牌，白色圆柱手柄，牌面红色叉号。角色至少一只手要握住牌柄，手柄从手中延伸到圆形牌面，牌面和手柄都完整入画，不能遮住角色脸。勾号或叉号必须在白色圆牌内部，不能漂浮在角色头顶或画面角落。

【禁止内容】
禁止白色贴纸描边、粗白边、光晕边、阴影背景、复杂场景、真实桌面透视、深色房间、蓝色屏幕光污染、大屏幕挡脸、大桌子挡身体、桌腿出框、椅子出框、角色半身裁切、头发出框、脚出框、手出框、道具出框、悬空勾号、悬空叉号、头顶漂浮符号、角落红叉、额头红叉、只有抱歉手势没有手持牌、无关文字、水印、logo。

输出格式：

一、角色身份锁定块
用一段文字描述参考图中这个角色必须保持不变的特征。

二、动作清单
用表格列出：状态、动作、道具、建议图片文件名。建议图片文件名必须严格使用上面的当前桌宠静态图命名格式。

三、静态生图提示词
每个状态单独给一条完整提示词，格式如下：

## 状态名称
用途：
建议图片文件名：
静态生图提示词：
负面提示词：
```

## 第二步：静态图质检提示词

用户生成静态图后，把图片发给 AI，并复制这段。

```text
请作为桌宠静态素材质检员，检查我生成的这些静态图是否合格。只检查静态图片本身，不讨论视频生成。

请逐张检查：
1. 是否和参考图是同一个角色。
2. 头身比、身高、腿长、脸型、发型、服装是否被改变。
3. 角色是否全身完整可见，头发、手、脚、道具是否被裁切。
4. 是否是纯色 chroma key green 绿幕背景，背景是否均匀、无阴影、无渐变、无场景。
5. 角色和所有道具是否都没有碰到画面边缘，顶部和底部是否至少保留 6%-10% 纯绿安全边距，左右是否至少保留 10%-16% 纯绿安全边距。
6. 任务进行中是否像“纯绿幕前的角色 + 小桌椅 + 笔记本组合立绘”，而不是办公室、房间、真实桌面场景、大显示器、大桌子、深色背景或蓝色屏幕光污染。
7. 任务完成是否是角色手持白色圆形牌，白色圆柱手柄，牌面绿色勾号；不能是头顶漂浮勾号。
8. 任务失败是否是角色手持白色圆形牌，白色圆柱手柄，牌面红色叉号；不能是头顶漂浮叉号、额头叉号或角落叉号。
9. 是否有白色贴纸描边、白边、光晕边。
10. 道具是否自然，是否误生成了带文字的卡片。
11. 角色边缘是否干净，是否有绿色反光、绿色污染或半透明绿边。

请输出：
1. 通过的图。
2. 需要返修的图。
3. 每张返修图的具体重写提示词。
4. 每张图不合格的原因。
```

## 第三步：图生视频提示词

静态首帧图确认后，复制下面这段给 AI，并附上通过质检的首帧图。

```text
你是桌宠图生视频提示词设计师。现在我已经有了通过质检的静态首帧图，请你为每张首帧图生成图生视频提示词。

全局硬性约束：
1. 全程固定镜头，固定机位原地拍摄。
2. 禁止推拉摇移、变焦、镜头晃动、画面尺度变化。
3. 角色从第一帧到最后一帧必须全身完整可见，头发到脚不能裁切。
4. 角色始终位于画面中央和原地，只允许角色自身和道具做小幅原地动作。
5. 不允许角色位移、滑动、漂移、跑出画面。
6. 保持参考图角色比例和画风，不要变高，不要拉长腿，不要改变头身比。
7. 如需要适配画面，只允许整体等比缩小。
8. 不要白色贴纸描边、白边、光晕边。
9. 不要无关文字、水印、logo。

循环状态规则：
任务进行中、任务暂停/休息这类会长时间停留的状态，必须无缝循环。第一帧和最后一帧要回到同一个姿态、表情、角色位置、道具位置、构图和镜头尺度。动作只能是小幅往返运动，例如呼吸、眨眼、发丝轻摆、手部轻微动作，不能突然加速、转身、缩放、漂移或停在半途。

一次性状态规则：
任务完成、任务失败、喝水提醒这类短动作，不要求无限循环，但开始和结束必须稳定，角色不能漂移，动作结束时停在清晰可读的状态，方便桌宠播放后自动切回待命或休息状态。

特殊规则：
1. 任务暂停/休息默认闭眼，除非我明确要求睁眼。
2. 任务完成必须保持角色手持白色圆形牌，白色圆柱手柄，牌面绿色勾号；角色的手必须握住牌柄，不能变成头顶漂浮勾号。
3. 任务失败必须保持角色手持白色圆形牌，白色圆柱手柄，牌面红色叉号；角色的手必须握住牌柄，不能变成头顶漂浮叉号、额头叉号或角落叉号。
4. 任务完成和任务失败的白色圆牌、手柄、绿色勾号或红色叉号都必须保留，不能在后续抠图或转透明时丢失。
5. 喝水提醒只需要喝水动作，不要出现“喝水”文字卡片。

请为每个状态输出：
1. 参考首帧图文件名。
2. 建议导出 MOV 文件名。
3. 建议最终 WebM 文件名。
4. 图生视频提示词。
5. 负面提示词。
6. 质检重点。
```

## 第四步：MOV 命名和交付提示词

生成视频后，把下面这段发给负责导出文件的人或 AI。

```text
请把生成好的桌宠视频导出为 MOV 或 WebM，并按下面标准命名：

1. 任务进行中_无缝循环.mov
2. 任务完成.mov
3. 任务失败.mov
4. 任务暂停_休息_无缝循环.mov
5. 喝水提醒.mov

如果可以导出透明背景 MOV，优先导出透明 MOV。
如果只能导出绿幕背景 MOV，请确保绿色背景纯净、角色边缘干净、角色和道具没有绿色污染。
不要改动角色比例，不要裁切头发、手、脚或道具。
```

## 第五步：MOV 转 WebM 提示词

当用户拿到 MOV 路径后，把路径发给支持本 Skill 的 Agent，复制下面这段。

```text
我已经有桌宠 MOV 视频，请帮我转成桌宠可用的透明 WebM。

要求：
1. 请先确认每个 MOV 文件是否存在。
2. 请根据文件名判断它对应哪个标准槽位。
3. 输出到 08_可替换素材/ 文件夹。
4. 输出文件名必须是：
   - 任务进行中_无缝循环.webm
   - 任务完成.webm
   - 任务失败.webm
   - 任务暂停_休息_无缝循环.webm
   - 喝水提醒.webm
5. 转换后请校验 WebM 是否存在、是否能被 ffprobe 读取、是否适合作为桌宠素材。

这是我的 MOV 路径：
请在这里粘贴 MOV 文件路径。
```

如果 MOV 是绿幕背景，请补充：

```text
这些 MOV 是绿幕背景，请使用绿幕抠像方式转成透明 WebM。
```

## 第六步：替换桌宠素材提示词

如果用户已经拿到最终 WebM，但不知道怎么替换，复制这段。

```text
我已经有 5 个桌宠 WebM 素材，请帮我检查并替换到桌宠项目的 08_可替换素材/ 文件夹。

请确认文件名是否符合：
1. 任务进行中_无缝循环.webm
2. 任务完成.webm
3. 任务失败.webm
4. 任务暂停_休息_无缝循环.webm
5. 喝水提醒.webm

请完成：
1. 检查文件是否存在。
2. 检查文件格式是否可读取。
3. 复制或替换到 08_可替换素材/。
4. 校验状态映射是否能找到这些文件。
5. 重启桌宠 App，让新素材生效。
```
