# 阿真桌宠桌面版

这个目录是桌宠真正出现在桌面上的运行版本，不是网页预览。

## 启动

直接双击：

- `阿真桌宠.app`

或者双击：

- `启动桌宠.command`

开发模式启动：

```bash
npm start
```

## 桌面形态

- 透明无边框窗口
- 默认出现在屏幕右下角
- 始终置顶
- 拖动小人即可移动位置
- 右键小人可打开设置、切换状态、替换素材、回到右下角
- 菜单栏可切换：任务进行中、任务完成、任务失败、任务暂停、喝水提醒
- 设置页可调整显示大小、动作停留时间、喝水提醒、休息时间

## Agent 事件入口

桌宠启动后，本地会监听：

```text
http://127.0.0.1:17876
```

触发事件：

```bash
curl "http://127.0.0.1:17876/event?name=agent.task.running"
curl "http://127.0.0.1:17876/event?name=agent.task.done"
curl "http://127.0.0.1:17876/event?name=agent.task.failed"
curl "http://127.0.0.1:17876/event?name=agent.waiting.user"
curl "http://127.0.0.1:17876/event?name=reminder.water.hourly"
```

桥接命令：

```bash
azhen-pet-event running
azhen-pet-event tool-running
azhen-pet-event done
azhen-pet-event failed
azhen-pet-event paused
azhen-pet-event water
```

通用 Agent 接入方式：

- 如果 Agent 支持 hooks / notify / shell command，在对应生命周期里调用 `azhen-pet-event` 即可。
- 如果 Agent 是命令行工具，可以用 `azhen-agent-pet <agent-command> [args...]` 包一层启动。
- 如果 Agent 有自己的插件、MCP 或脚本系统，只要最终能请求 `http://127.0.0.1:17876/event?name=...`，就可以接入。
- 桌宠没有启动时，桥接命令会静默退出，不会阻断原 Agent。

通用 CLI 示例：

```bash
azhen-agent-pet codex
azhen-agent-pet aider --model sonnet
azhen-agent-pet goose session
```

推荐所有 Agent 统一发送这 5 类标准事件：

| 标准事件 | 桌宠动作 |
|---|---|
| `agent.task.running` | 任务进行中 |
| `agent.tool.running` | 任务进行中 |
| `agent.task.done` | 任务完成 |
| `agent.task.failed` | 任务失败 |
| `agent.waiting.user` | 任务暂停/休息 |

Claude Code 已通过全局 hooks 自动接入：

| Claude Code hook | 桌宠动作 |
|---|---|
| UserPromptSubmit | 任务进行中 |
| PreToolUse | 任务进行中 |
| Stop | 任务完成 |
| StopFailure | 任务失败 |

Codex 第一版是基础桥接：

- `~/.codex/config.toml` 的 `notify` 已接入 `azhen-pet-codex-notify`，回合结束时显示任务完成。
- 可选使用 `codex-pet` 启动 Codex CLI：启动时显示任务进行中，正常退出显示任务完成，异常退出显示任务失败。
- Codex Desktop 暂不承诺完整的“开始/工具运行”自动状态，因为当前未发现稳定的对应 hook；其它 Agent 也是同理，能否自动跟随取决于该 Agent 是否暴露 hooks、notify、插件或可包装的 CLI。

通用状态映射：

| 进程状态 | 桌宠动作 |
|---|---|
| running / streaming / tool_running | 任务进行中 |
| completed / output_ready | 任务完成 |
| failed / error | 任务失败 |
| waiting_user / waiting_approval / paused / idle / blocked | 任务暂停/休息 |
| reminder.water.hourly | 喝水提醒 |

默认动态表情：

| 动态素材 | 代表含义 | 默认显示时机 |
|---|---|---|
| 任务进行中_无缝循环 | Agent 正在处理任务 | 任务开始、运行中、工具调用中、流式输出中 |
| 任务完成 | Agent 已完成输出 | 任务完成、输出完成、结果已准备好 |
| 任务失败 | Agent 运行失败或工具报错 | 任务失败、执行失败、工具错误 |
| 任务暂停_休息_无缝循环 | Agent 等待或用户休息时间 | 等待用户、等待授权、暂停、空闲、blocked、午休/休息 |
| 喝水提醒 | 工作提醒喝水 | 工作时间内按设置间隔触发 |

循环策略：

- 任务进行中、任务暂停/休息使用 `*_无缝循环.webm`、同名 GIF 或同名 WebP
- 这两个长期状态采用 ping-pong 循环，让尾帧回到首帧
- 任务完成、任务失败是一次性动作，播放后按状态映射自动回退到任务暂停/休息
- 喝水提醒会按设置页里的停留时间循环显示，推荐 1-2 分钟

标准素材替换：

- `08_可替换素材/任务进行中_无缝循环.*`
- `08_可替换素材/任务完成.*`
- `08_可替换素材/任务失败.*`
- `08_可替换素材/任务暂停_休息_无缝循环.*`
- `08_可替换素材/喝水提醒.*`

也可以在设置页逐个选择文件，桌宠会自动复制到 `08_可替换素材`。
支持 `.gif`、`.webp`、`.webm`、`.apng`、`.png`、`.mp4`。同名素材同时存在时，优先级是 `.gif -> .webp -> .webm -> .apng -> .png -> .mp4`。

按状态直接指定素材路径：

```bash
curl "http://127.0.0.1:17876/assets/replace?state=done&path=/你的路径/任务完成.gif"
```

调整显示大小：

```bash
curl "http://127.0.0.1:17876/settings?size=300"
curl "http://127.0.0.1:17876/settings?size=420"
curl "http://127.0.0.1:17876/settings?size=560"
```

打开设置窗口：

```bash
curl "http://127.0.0.1:17876/settings/open"
```

健康检查：

```bash
curl "http://127.0.0.1:17876/health"
```
