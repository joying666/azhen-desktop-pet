# 可替换素材包

这个目录是给普通用户换桌宠素材用的。

## 最简单用法

打开桌宠后，右键小人，进入 `设置...`，在 `标准素材` 里逐个点击 `替换`：

- 进行中
- 完成
- 失败
- 暂停/休息
- 喝水

设置页会自动把你选择的文件复制成中文标准文件名，并删除同状态旧文件。

## 手动替换

把你的动画文件放进这个目录，并使用下面 5 个文件名：

| 文件名 | 对应状态 |
|---|---|
| `任务进行中_无缝循环.webm` / `.gif` / `.webp` / `.apng` / `.png` | 任务进行中 |
| `任务完成.webm` / `.gif` / `.webp` / `.apng` / `.png` | 任务完成 |
| `任务失败.webm` / `.gif` / `.webp` / `.apng` / `.png` | 任务失败 |
| `任务暂停_休息_无缝循环.webm` / `.gif` / `.webp` / `.apng` / `.png` | 任务暂停/休息 |
| `喝水提醒.webm` / `.gif` / `.webp` / `.apng` / `.png` | 喝水提醒 |

桌宠会按这个优先级自动寻找文件：

```text
.gif -> .webp -> .webm -> .apng -> .png -> .mp4
```

如果你想用 GIF 或 WebP，把同名 `.gif` / `.webp` 放进来即可；它们会优先替换同名 `.webm`。设置页里每个状态也都可以单独选择 GIF 或 WebP 文件。

## 推荐格式

- 最推荐：透明背景 `WebM`
- 次推荐：透明背景 `WebP` 或 `APNG`
- 可用：`GIF`
- 静态占位：`PNG`

## 动画建议

- `任务进行中_无缝循环` 和 `任务暂停_休息_无缝循环` 是长期循环状态，最好做成首帧尾帧一致的无缝 loop。
- `done`、`failed` 是一次性动作，播放后会自动回到 `working` 或 `paused`。
- `water` 会按设置页里的停留时间循环显示，适合设置为 1-2 分钟。
- 尺寸建议 1:1 正方形，透明背景，角色完整居中。

## 时间设置

设置页可以调整：

- 完成动作停留秒数
- 失败动作停留秒数
- 喝水动作停留分钟数
- 喝水提醒间隔与工作时间
- 午休/休息时间，休息时复用 `paused` 素材

## 事件映射

事件映射写在 `状态映射.json`。通常不需要改它，只替换素材即可。

桌宠默认使用通用 Agent 事件，不绑定某一个 Agent：

| 标准事件 | 对应状态 |
|---|---|
| `agent.task.running` | 任务进行中 |
| `agent.tool.running` | 任务进行中 |
| `agent.task.done` | 任务完成 |
| `agent.task.failed` | 任务失败 |
| `agent.waiting.user` | 任务暂停/休息 |
| `reminder.water.hourly` | 喝水提醒 |

如果你的 Agent 支持 hooks、notify、脚本、插件或 MCP，让它在对应时机调用 `azhen-pet-event` 即可。命令行 Agent 也可以用 `azhen-agent-pet <agent-command> [args...]` 包一层启动。
